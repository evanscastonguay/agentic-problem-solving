# 3 Define

> Step 3 of 6 — Define the problem statement, constraints, and success criteria before exploring solutions. Use when the user asks to define a problem or write a problem statement, or when scope and success criteria are unclear before choosing a solution.

- state the problem in one sentence
- explain why it matters (impact)
- list constraints and context (what must not change)
- define success criteria (how we know it's done)
- list assumptions and unknowns
