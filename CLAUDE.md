# CLAUDE.md

Skills for AI coding agents (markdown with YAML frontmatter) and one script that deploys them. No application code, no tests, no CI.

- `skills/<name>/SKILL.md` is the only source. Codex/Cursor prompts and Windsurf workflows are generated by `release.sh` at deploy time and are not committed.
- `description` must be one line and say when to use the skill ("Use when the user asks to ..."). Names: lowercase, digits, hyphens; `s1`…`s6` are the ordered chain.
- `./release.sh --all` deploys everywhere; `--target claude|codex|cursor|windsurf` for one tool; `--extra-skills <dir>` overlays private skills; `--dry-run` previews. Each target folder is replaced (rsync `--delete`).
- Public, MIT. Never commit employer or client identifiers, internal hosts, ticket keys, or third-party transcripts. Private skills live outside this repo and deploy with `--extra-skills`.
