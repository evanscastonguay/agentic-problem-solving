# s4-solutions Workflow

- use first principles to identify the core of the problem
- provide 3 genuinely distinct solutions (conservative to innovative)
- for each, give 3 specific pros and 3 specific cons
- recommend the simplest effective solution that addresses the core
- explain the reasoning behind the recommendation
