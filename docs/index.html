Six ordered skills that turn an unpredictable AI coding agent into a dependable collaborator. Free, MIT-licensed, drop-in for Claude Code and Cursor.

The six steps

Run them in order, or jump in where you are. Each step hands the AI one thing it was missing.

StepWhat it doesHands the AI
1 · ExploreUnderstand the system before touching itContext
2 · ClarifyAsk the questions that kill ambiguityPrecision
3 · DefineLock the problem, constraints, success criteriaA target
4 · SolutionsCompare 3 approaches, pick the simplestA strategy
5 · PlanWrite a phased plan you can resume fromMemory
6 · ImplementBuild test-first, then verify the resultAccountability

The magic isn't any single step — it's that together they force you to transfer understanding instead of hoping a prompt lands.

Not just for code

The same chain works for any complex problem you'd hand a sharp collaborator — strategy, planning, writing, analysis, research. Code is just where the payoff is easiest to see.

Install in 30 seconds

git clone https://github.com/evanscastonguay/agentic-problem-solving.git
cd agentic-problem-solving && ./release.sh --all

Deploys to Claude Code, Codex, Cursor, and Windsurf in one go. They sort s1…s6 in your skill picker, so the order is always in front of you.
