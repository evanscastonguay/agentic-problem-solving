# Résoudre des problèmes avec un agent IA

A French talk (about 60 minutes, 32 slides) by Evans Castonguay for Master's students in innovation and finance. It teaches the six-step method in this repository to a non-technical audience.

## Structure

1. **Les types d'IA**: four nested circles (AI, machine learning, deep learning, generative AI), and where ChatGPT fits.
2. **Comment fonctionne ChatGPT**: training data, how it is built (read, imitate, practise), training vs inference, memory vs tools.
3. **Bien l'utiliser**: the paradox, the context bridge, the smart-intern mental model, and the six steps applied to a finance example (Q3 budget variances), with an in-room exercise.
