# Prompting Toolbelt Slide (Insert After "Bring the Team and Tools")

## Slide Title
Prompting Toolbelt: From Chat to Delegation

## On-Slide Bullets (Keep to One Screen)
- State the outcome in one sentence.
- Add context and constraints.
- Specify output format.
- Ask for verification or next steps.

## 30-Second Talk Track
"Here is the smallest prompt that changes everything. We stop asking for a
step, and we delegate the outcome. One sentence for the goal, the context it
needs, the format we want back, and a quick verification step. That is the
toolbelt."

## Before / After Example (Use One, Not Both)

### Before (Chat-Level)
"Write a function to parse this file."

### After (Outcome-Level Delegation)
"Goal: find the bug in this folder and propose a fix.
Context: the error appears in file upload, stack trace attached.
Constraints: do not change public APIs; keep changes minimal.
Output: 3 bullets (root cause, fix, verification).
Verify: include the exact test or command to validate."
